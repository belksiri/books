Data science avec Python, pas à pas

Un seul projet, de l'installation à la décision : explorer, prédire et segmenter des clients

Belk Siri

Apprendre la data science avec Python en menant un seul projet, du premier notebook à la recommandation finale : préparer et explorer les données, prédire, évaluer, segmenter. Cette page réunit les données, les notebooks et les fichiers d'exercices qui accompagnent le livre.

Vérifier le téléchargement

L'empreinte SHA-256 de l'archive doit être exactement :

f63cdf2b4cb0306e46371ec24c01ce584013ca088e6b2ea5f70c5596fec6eb0e

macOS (Terminal)

shasum -a 256 Ressources_Lecteur_v1.0.1.zip

Windows (PowerShell)

Get-FileHash Ressources_Lecteur_v1.0.1.zip -Algorithm SHA256

Installer

Décompresse l'archive dans ton dossier Documents, puis ouvre un terminal dans le dossier data_science_python_pas_a_pas. Pour un premier résultat sans rien installer, ouvre notebooks/00_demarrage_express.ipynb dans VS Code ou Google Colab.

macOS

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
python -m smartmarket.verifier_environnement

Windows (PowerShell)

py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
python -m smartmarket.verifier_environnement

Le diagnostic doit se terminer par « Environnement SmartMarket prêt. ». Si PowerShell refuse l'activation : Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, puis recommence.

Vérifié sous macOS avec Python 3.12, 3.13 et 3.14. Compatibilité Windows préparée et revue statiquement, mais non validée sur une machine Windows.

Ce que contient l'archive

  • les données du projet fictif SmartMarket : export brut, fichier propre, clients à scorer ;
  • un notebook par chapitre, les notebooks des annexes et les énoncés des exercices et des défis (65 notebooks) ;
  • le code du projet, les tests et un script de vérification pour Windows.

Corrigés. Les corrigés rédigés sont dans l'annexe G du livre. Les notebooks corrigés et les fichiers de vérité des données sont distribués séparément et ne sont pas publiés sur cette page.

Toutes les données sont fictives : aucune ne décrit une personne ou une entreprise réelle.
