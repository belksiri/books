## Démarrer

1. Télécharge l'archive et vérifie son empreinte (voir
   [le guide d'installation](documentation/GUIDE_INSTALLATION.md)).
2. Décompresse-la dans ton dossier Documents : tu obtiens le dossier
   `data_science_python_pas_a_pas`.
3. Pour un premier résultat sans rien installer, ouvre
   `notebooks/00_demarrage_express.ipynb` dans VS Code ou Google Colab.
4. Pour le projet complet, suis le chapitre 4 du livre ou le
   [guide d'installation](documentation/GUIDE_INSTALLATION.md).

Python 3.12, 3.13 ou 3.14.
