Primeros pasos

  1. Instala uv

    También instala Python si hace falta. En macOS con Homebrew:

    brew install uv

    Para Linux, Windows o sin Homebrew, sigue la documentación de uv.

  2. Descomprime el archivo y entra en code/

    En la carpeta donde lo descargaste:

    unzip vos-premiers-agents-ia-code.zip
cd code

    Todos los comandos del libro se lanzan desde esta carpeta.

  3. Instala las versiones del libro y ejecuta los tests

    Los tests funcionan sin clave ni red, con un modelo simulado:

    uv sync --locked
uv run pytest

    Lo que cuenta: varios passed, ningún failed.

  4. Lanza una primera demostración

    Una misión simulada y gratuita:

    uv run assistant demo
Más adelante en el libro
  • Para la página web del capítulo 11: uv sync --locked --extra interface.
  • Las llamadas a un modelo real pasan por una API de pago y están cerradas por defecto. El capítulo 2 explica la clave, el interruptor ASSISTANT_ALLOW_LIVE y los límites de gasto. No compartas nunca tu clave.
Requisitos, versiones y limitaciones

Requisitos

  • Las bases de Python.
  • Un ordenador con macOS, Linux o Windows (solo se probó macOS), con un terminal.
  • uv, que instala Python 3.12 si hace falta.
  • Ninguna clave ni cuenta para seguir el libro: los tests y las demostraciones usan un modelo simulado. Una clave de API de pago solo sirve para las pruebas reales, opcionales.

Versiones utilizadas

Python3.12.4 (≥ 3.11)
uv0.12.10
anthropic (SDK)2.3.0
pydantic2.14.2
streamlit1.66.1

Limitaciones conocidas

  • Probado solo en macOS (Apple Silicon) con Python 3.12.4 y uv 0.12.10; Linux y Windows están documentados pero sin probar; la página web solo se vio en Chrome.
