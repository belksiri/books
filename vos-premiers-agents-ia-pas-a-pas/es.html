Instalación

  1. Instala uv, que también instala Python si hace falta.
  2. Descomprime el archivo del código y sitúate en la carpeta code/.
  3. Ejecuta uv sync --locked y luego uv run pytest: los tests funcionan sin clave, con un modelo simulado.
  4. Ejecuta uv run assistant demo para una primera demostración gratuita.
  5. Para la página web del capítulo 11: uv sync --locked --extra interface.
  6. Las llamadas a un modelo real son de pago y están cerradas por defecto: sigue el capítulo 2 (clave en code/.env, interruptor ASSISTANT_ALLOW_LIVE, límites de gasto). No compartas nunca tu clave.

Limitaciones conocidas

  • Probado solo en macOS (Apple Silicon) con Python 3.12.4 y uv 0.12.10; Linux y Windows están documentados pero sin probar; la página web solo se vio en Chrome.
  • Las pruebas reales son pocas, del 5 de noviembre de 2026, en francés, con un solo modelo; los precios y modelos del proveedor cambian.
  • No se probó ningún despliegue en un servidor; el recurso Docker nunca se construyó.
  • Las ediciones inglesa, española y alemana no han tenido revisión humana nativa.
