Installation

  1. Installez uv, qui installe aussi Python si nécessaire.
  2. Décompressez l'archive du code, puis placez-vous dans le dossier code/.
  3. Lancez uv sync --locked, puis uv run pytest : les tests tournent sans clé, avec un modèle simulé.
  4. Lancez uv run assistant demo pour une première démonstration gratuite.
  5. Pour la page web du chapitre 11 : uv sync --locked --extra interface.
  6. Les appels à un vrai modèle sont payants et fermés par défaut : suivez le chapitre 2 (clé dans code/.env, interrupteur ASSISTANT_ALLOW_LIVE, limites de dépense). Ne partagez jamais votre clé.

Limites connues

  • Testé seulement sur macOS (Apple Silicon) avec Python 3.12.4 et uv 0.12.10 ; Linux et Windows sont documentés mais non testés ; la page web n'a été vue que dans Chrome.
  • Les essais réels sont peu nombreux, datés du 5 novembre 2026, en français, avec un seul modèle ; les prix et les modèles du fournisseur changent.
  • Aucun déploiement sur un serveur n'a été testé ; la ressource Docker n'a jamais été construite.
  • Les éditions anglaise, espagnole et allemande n'ont pas eu de relecture native humaine.
