Pour commencer

  1. Installez uv

    Il installe aussi Python si nécessaire. Sur macOS avec Homebrew :

    brew install uv

    Pour Linux, Windows ou sans Homebrew, suivez la documentation de uv.

  2. Décompressez l'archive et entrez dans code/

    Dans le dossier où vous l'avez téléchargée :

    unzip vos-premiers-agents-ia-code.zip
cd code

    Toutes les commandes du livre se lancent depuis ce dossier.

  3. Installez les versions du livre et lancez les tests

    Les tests tournent sans clé ni réseau, avec un modèle simulé :

    uv sync --locked
uv run pytest

    Ce qui compte : des passed, aucun failed.

  4. Lancez une première démonstration

    Une mission simulée, gratuite :

    uv run assistant demo
Plus tard dans le livre
  • Pour la page web du chapitre 11 : uv sync --locked --extra interface.
  • Les appels à un vrai modèle passent par une API payante et sont fermés par défaut. Le chapitre 2 explique la clé, l'interrupteur ASSISTANT_ALLOW_LIVE et les limites de dépense. Ne partagez jamais votre clé.

Limites connues

  • Testé seulement sur macOS (Apple Silicon) avec Python 3.12.4 et uv 0.12.10 ; Linux et Windows sont documentés mais non testés ; la page web n'a été vue que dans Chrome.
  • Les essais réels sont peu nombreux, datés du 5 novembre 2026, en français, avec un seul modèle ; les prix et les modèles du fournisseur changent.
  • Aucun déploiement sur un serveur n'a été testé ; la ressource Docker n'a jamais été construite.
  • Les éditions anglaise, espagnole et allemande n'ont pas eu de relecture native humaine.

À propos de l'auteur

Belk Siri est ingénieur en informatique et en radiocommunications, et consultant senior fort de 26 ans d’expérience. Très tôt passionné par l’intelligence artificielle, il a développé son expertise en data science et en exploitation des données, tout en explorant la radio logicielle avec GNU Radio. Il accompagne les entreprises dans l’adoption de ces technologies et la montée en compétences de leurs équipes, avec une approche concrète et accessible. À travers ses ouvrages, il transmet son expérience pour rendre la radio logicielle, l’intelligence artificielle et la data science accessibles, et guider ses lecteurs pas à pas vers la pratique.
