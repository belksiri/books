Installation

  1. Installieren Sie uv; es installiert bei Bedarf auch Python.
  2. Entpacken Sie das Code-Archiv und wechseln Sie in den Ordner code/.
  3. Starten Sie uv sync --locked, dann uv run pytest: Die Tests laufen ohne Schlüssel, mit einem simulierten Modell.
  4. Starten Sie uv run assistant demo für eine erste kostenlose Vorführung.
  5. Für die Webseite aus Kapitel 11: uv sync --locked --extra interface.
  6. Aufrufe eines echten Modells sind kostenpflichtig und standardmäßig gesperrt: Folgen Sie Kapitel 2 (Schlüssel in code/.env, Schalter ASSISTANT_ALLOW_LIVE, Ausgabengrenzen). Geben Sie Ihren Schlüssel nie weiter.
