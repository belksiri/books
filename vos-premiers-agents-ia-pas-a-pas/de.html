Erste Schritte

  1. uv installieren

    Es installiert bei Bedarf auch Python. Unter macOS mit Homebrew:

    brew install uv

    Für Linux, Windows oder ohne Homebrew folgen Sie der Dokumentation von uv.

  2. Archiv entpacken und in code/ wechseln

    Im Ordner, in den Sie es heruntergeladen haben:

    unzip vos-premiers-agents-ia-code.zip
cd code

    Alle Befehle des Buches werden in diesem Ordner gestartet.

  3. Die Versionen des Buches installieren und die Tests starten

    Die Tests laufen ohne Schlüssel und ohne Netz, mit einem simulierten Modell:

    uv sync --locked
uv run pytest

    Entscheidend: einige passed, kein failed.

  4. Eine erste Vorführung starten

    Eine simulierte, kostenlose Mission:

    uv run assistant demo
Später im Buch
  • Für die Webseite aus Kapitel 11: uv sync --locked --extra interface.
  • Aufrufe eines echten Modells laufen über eine kostenpflichtige API und sind standardmäßig gesperrt. Kapitel 2 erklärt den Schlüssel, den Schalter ASSISTANT_ALLOW_LIVE und die Ausgabengrenzen. Geben Sie Ihren Schlüssel nie weiter.
