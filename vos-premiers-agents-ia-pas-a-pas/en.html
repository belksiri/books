Getting started

  1. Install uv

    It also installs Python if needed. On macOS with Homebrew:

    brew install uv

    For Linux, Windows or without Homebrew, follow the uv documentation.

  2. Unzip the archive and move into code/

    In the folder where you downloaded it:

    unzip vos-premiers-agents-ia-code.zip
cd code

    Every command in the book runs from this folder.

  3. Install the book’s versions and run the tests

    The tests run without a key or network, with a simulated model:

    uv sync --locked
uv run pytest

    What matters: some passed, no failed.

  4. Run a first demonstration

    A simulated, free mission:

    uv run assistant demo
Later in the book
  • For the chapter 11 web page: uv sync --locked --extra interface.
  • Calls to a real model go through a paid API and are off by default. Chapter 2 explains the key, the ASSISTANT_ALLOW_LIVE switch and the spending limits. Never share your key.

Known limitations

  • Tested only on macOS (Apple Silicon) with Python 3.12.4 and uv 0.12.10; Linux and Windows are documented but untested; the web page was only seen in Chrome.
  • The real trials are few, dated November 5, 2026, in French, with a single model; the provider’s prices and models change.
  • No server deployment was tested; the Docker resource was never built.
  • The English, Spanish and German editions have had no native human review.
