Installation

  1. Install uv, which also installs Python if needed.
  2. Unzip the code archive, then move into the code/ folder.
  3. Run uv sync --locked, then uv run pytest: the tests run without a key, with a simulated model.
  4. Run uv run assistant demo for a first free demonstration.
  5. For the chapter 11 web page: uv sync --locked --extra interface.
  6. Calls to a real model are paid and off by default: follow chapter 2 (key in code/.env, ASSISTANT_ALLOW_LIVE switch, spending limits). Never share your key.

Known limitations

  • Tested only on macOS (Apple Silicon) with Python 3.12.4 and uv 0.12.10; Linux and Windows are documented but untested; the web page was only seen in Chrome.
  • The real trials are few, dated November 5, 2026, in French, with a single model; the provider’s prices and models change.
  • No server deployment was tested; the Docker resource was never built.
  • The English, Spanish and German editions have had no native human review.
