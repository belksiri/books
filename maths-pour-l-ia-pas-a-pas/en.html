How to use

In your browser, nothing to installeasiest

Click “Open in Colab” next to the notebook you want (a Google account is required), then run the cells in order. To keep your answers: File > Save a copy in Drive.

On your computer

  1. Install Python and Jupyter

    Python 3.10 or later. The simplest option is Anaconda, which already includes Jupyter and the libraries you need.

  2. Unzip the archive and go into its folder

    In the folder where you downloaded it:

    unzip maths-pour-l-ia-pas-a-pas-ressources-fr.zip
cd maths-pour-l-ia-pas-a-pas-ressources-fr

  3. Install the libraries and check the installation

    Only once:

    python -m pip install -r requirements.txt
python verifier_installation.py

    Every line should start with OK.

  4. Start Jupyter and open the first notebook

    jupyter notebook

    Then open notebooks/ch01_a_completer.ipynb and run the cells in order (Shift + Enter).

Good to know
  • As long as an answer is missing, the check cell displays “pas encore complété” (not yet completed), without an error.
  • Each notebook starts with an import cell, then a data cell: run them first.
  • The CSV files in the donnees/ folder let you open the data in a spreadsheet; the notebooks do not need them.
Prerequisites, versions and limitations

Prerequisites

  • The book, for the lessons and the pen-and-paper exercises.
  • In Colab: a browser and a Google account, nothing to install.
  • On your computer: Python 3.10 or later, numpy, pandas, matplotlib and Jupyter; scikit-learn is optional (one comparison in chapter 4).

Tested versions

Python3.12.4
numpy1.26.4
pandas2.2.2
matplotlib3.8.4
scikit-learn1.4.2 (facultatif)

Known limitations

  • Full runs of the 14 notebooks checked on macOS (Apple Silicon) with the versions above; Linux and Windows are not tested.
  • The notebooks, data and instructions are in French.
