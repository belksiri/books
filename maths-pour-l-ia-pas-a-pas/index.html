Mode d'emploi

Dans le navigateur, sans rien installerle plus simple

Cliquez sur « Ouvrir dans Colab » à côté du notebook voulu (un compte Google est nécessaire), puis exécutez les cellules dans l'ordre. Pour garder vos réponses : Fichier > Enregistrer une copie dans Drive.

Sur votre ordinateur

  1. Installez Python et Jupyter

    Python 3.10 ou plus récent. Le plus simple : Anaconda, qui contient déjà Jupyter et les bibliothèques utiles.

  2. Décompressez l'archive et entrez dans son dossier

    Dans le dossier où vous l'avez téléchargée :

    unzip maths-pour-l-ia-pas-a-pas-ressources-fr.zip
cd maths-pour-l-ia-pas-a-pas-ressources-fr

  3. Installez les bibliothèques et vérifiez l'installation

    Une seule fois :

    python -m pip install -r requirements.txt
python verifier_installation.py

    Chaque ligne doit commencer par OK.

  4. Lancez Jupyter et ouvrez le premier notebook

    jupyter notebook

    Puis ouvrez notebooks/ch01_a_completer.ipynb et exécutez les cellules dans l'ordre (Maj + Entrée).

Bon à savoir
  • Tant qu'une réponse manque, la cellule de vérification affiche « pas encore complété », sans erreur.
  • Chaque notebook commence par une cellule d'import, puis une cellule de données : exécutez-les d'abord.
  • Les fichiers CSV du dossier donnees/ servent à ouvrir les données dans un tableur ; les notebooks n'en ont pas besoin.
Prérequis, versions et limites

Prérequis

  • Le livre, pour les leçons et les exercices sur papier.
  • Dans Colab : un navigateur et un compte Google, rien à installer.
  • Sur votre ordinateur : Python 3.10 ou plus récent, numpy, pandas, matplotlib et Jupyter ; scikit-learn est facultatif (une comparaison du chapitre 4).

Versions testées

Python3.12.4
numpy1.26.4
pandas2.2.2
matplotlib3.8.4
scikit-learn1.4.2 (facultatif)

Limites connues

  • Exécution complète des 14 notebooks vérifiée sur macOS (Apple Silicon) avec les versions ci-dessus ; Linux et Windows ne sont pas testés.
  • Les notebooks, les données et le mode d'emploi sont en français.
Contenu de l'archive et empreintes
