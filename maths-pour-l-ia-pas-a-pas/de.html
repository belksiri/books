Anleitung

Im Browser, ohne Installationam einfachsten

Klicken Sie neben dem gewünschten Notebook auf „In Colab öffnen“ (ein Google-Konto ist erforderlich) und führen Sie die Zellen der Reihe nach aus. Um Ihre Antworten zu behalten: Datei > Kopie in Drive speichern.

Auf Ihrem Computer

  1. Python und Jupyter installieren

    Python 3.10 oder neuer. Am einfachsten: Anaconda, das Jupyter und die benötigten Bibliotheken bereits enthält.

  2. Archiv entpacken und in seinen Ordner wechseln

    Im Ordner, in den Sie es heruntergeladen haben:

    unzip maths-pour-l-ia-pas-a-pas-ressources-de.zip
cd maths-pour-l-ia-pas-a-pas-ressources-de

  3. Bibliotheken installieren und Installation prüfen

    Nur einmal:

    python -m pip install -r requirements.txt
python verifier_installation.py

    Jede Zeile sollte mit OK beginnen.

  4. Jupyter starten und das erste Notebook öffnen

    jupyter notebook

    Öffnen Sie dann notebooks/ch01_a_completer.ipynb und führen Sie die Zellen der Reihe nach aus (Umschalt + Eingabe).

Gut zu wissen
  • Solange eine Antwort fehlt, zeigt die Prüfzelle „noch nicht ausgefüllt“ an, ohne Fehlermeldung.
  • Jedes Notebook beginnt mit einer Import-Zelle und einer Datenzelle: Führen Sie diese zuerst aus.
  • Mit den CSV-Dateien im Ordner donnees/ können Sie die Daten in einer Tabellenkalkulation öffnen; die Notebooks brauchen sie nicht.
Voraussetzungen, Versionen und Grenzen

Voraussetzungen

  • Das Buch, für die Lektionen und die Aufgaben auf Papier.
  • In Colab: ein Browser und ein Google-Konto, keine Installation.
  • Auf Ihrem Computer: Python 3.10 oder neuer, numpy, pandas, matplotlib und Jupyter; scikit-learn ist optional (ein Vergleich in Kapitel 4).

Getestete Versionen

Python3.12.4
numpy1.26.4
pandas2.2.2
matplotlib3.8.4
scikit-learn1.4.2 (facultatif)

Bekannte Grenzen

  • Vollständige Ausführung der 18 Notebooks unter macOS (Apple Silicon) mit den obigen Versionen geprüft; Linux und Windows sind nicht getestet.
  • Die Bezeichner im Code sind in allen Ausgaben englisch. Die CSV-Dateien behalten die Spaltennamen des französischen Buchs; die Variablentabelle jedes Notebooks nennt Bedeutung, Einheit und Entsprechung.
