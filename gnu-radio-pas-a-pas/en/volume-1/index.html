One archive for every edition

The resources are shared by all editions of the book. A .grc file holds official GNU Radio block names, numbers and identifiers — nothing that needs translating. The English edition therefore downloads exactly the same archive as the French one, and the file names do not change.

This is why the archive is still called gnu-radio-pas-a-pas-volume-1-resources.zip: renaming it would break the checksums printed in the French edition, which is already published. For the same reason the README.txt inside it is in French; the same text in English is README-volume-1.txt.

Verify your download

The SHA-256 checksum of the archive must be exactly:

1404c04535879b422eb6fe1c0e9ff7965c2f83f7a2b5ea03bc19dd08da5b4072

Compare it with the one computed on the file you received:

macOS or Linux

shasum -a 256 gnu-radio-pas-a-pas-volume-1-resources.zip

Windows (PowerShell)

Get-FileHash gnu-radio-pas-a-pas-volume-1-resources.zip -Algorithm SHA256

The checksums of every file, one by one, are in the volume manifest and in SHA256SUMS.

What you need

Software

  • GNU Radio 3.10.12.0, or a more recent version of the 3.10 series;
  • installed preferably by Radioconda 2025.03.14;
  • a version earlier than 3.8 will not be able to read these files: the format changed between 3.7 and 3.8.

Hardware

  • a macOS or Windows computer;
  • a sound card for the flowgraphs that produce sound;
  • no radio receiver: this volume is entirely in simulation.

Using the files

  1. Unzip the archive into your working folder.
  2. Copy the whole folder of the chapter or the hands-on exercise into your own flowgraphs/ folder, then work on the copy. The exercises will have you change values; the original lets you go back to the starting point without downloading again.
  3. Open the .grc file in GNU Radio Companion: menu File, then Open.
  4. F5 generates the program, F6 runs it, F7 stops it.

Copy the folder, not just the .grc file. The flowgraphs that read book-audio.wav name it by itself, so in the current folder. The audio file sits next to them for that reason.

The Python program that GRC writes next to the .grc file is rebuilt at every generation. It is not provided here, and there is never any reason to edit it or to save it.

Two files are not provided, because you are the one who produces them: echantillons.iq, written by the flowgraph of Exercise 8, and the .cfile of real samples recorded in Exercise 18.

Chapters that need a receiver

No flowgraph in this volume requires a radio receiver. Everything runs in simulation. A sound card is enough for the flowgraphs that produce sound; the receiver only comes into play in Volume 2.
