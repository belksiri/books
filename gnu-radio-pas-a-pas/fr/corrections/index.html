Signaler un problème

Un montage qui refuse de s'ouvrir, un fichier manquant, une empreinte qui ne correspond pas : ouvrez un signalement sur GitHub en indiquant le volume, le chemin du fichier et votre version de GNU Radio.

Ce qui n'est pas publié ici

Cette page ne distribue que les fichiers dont le lecteur a besoin. Ne sont pas publiés : le texte du livre, les fichiers de composition, les couvertures, les documents de travail, et les programmes Python que GNU Radio Companion produit lui-même — ceux-là sont reconstruits à chaque génération.

Deux fichiers de travaux pratiques ne sont pas fournis non plus, parce que c'est le lecteur qui les produit : echantillons.iq (TP 8) et le fichier .cfile d'échantillons réels (TP 18).
