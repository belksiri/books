Comparez-la à celle du fichier reçu :

Les empreintes de tous les fichiers, un par un, sont dans le manifeste du volume et dans SHA256SUMS.

Ce qu'il faut avoir

Logiciel

  • GNU Radio 3.10.12.0, ou une version plus récente de la série 3.10 ;
  • installé de préférence par Radioconda 2025.03.14 ;
  • une version antérieure à 3.8 ne saura pas lire ces fichiers : le format a changé entre 3.7 et 3.8.

Matériel

  • un ordinateur macOS ou Windows ;
  • une carte son pour les montages qui produisent du son ;
  • aucun récepteur radio : ce volume est entièrement en simulation.

Utiliser les fichiers

  1. Décompressez l'archive dans votre dossier de travail.
  2. Copiez le dossier entier du chapitre ou du travail pratique dans votre propre dossier flowgraphs/, puis travaillez sur la copie. Les exercices vous feront modifier des valeurs ; l'original permet de revenir au point de départ sans retélécharger.
  3. Ouvrez le fichier .grc dans GNU Radio Companion : menu File, puis Open.
  4. F5 génère le programme, F6 l'exécute, F7 l'arrête.

Copiez le dossier, pas seulement le fichier .grc. Les montages qui lisent book-audio.wav le désignent par son nom seul, donc dans le dossier courant. Le fichier son est déposé à côté d'eux pour cette raison.

Le programme Python que GRC écrit à côté du fichier .grc est reconstruit à chaque génération. Il n'est pas fourni ici, et il n'y a jamais lieu de le modifier ni de le sauvegarder.

Deux fichiers ne sont pas fournis, parce que c'est vous qui les produisez : echantillons.iq, écrit par le montage du TP 8, et le fichier .cfile d'échantillons réels enregistré au TP 18.

macOS et Windows

Les fichiers sont les mêmes sur les deux systèmes : ce sont des fichiers texte, indépendants de la plateforme. Ce qui diffère, c'est ce qui a été vérifié.

Chapitres qui demandent un récepteur

Aucun montage de ce volume n'exige de récepteur radio. Tout fonctionne en simulation. Une carte son suffit pour les montages qui produisent du son ; le récepteur n'entre en jeu qu'au volume 2.
